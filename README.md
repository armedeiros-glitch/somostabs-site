# TABS Site V2

Arquivos:
- index.html
- styles.css
- app.js

Para publicar no repositório `somostabs-site`:
1. Substitua o `index.html` atual.
2. Adicione `styles.css` e `app.js` na raiz do repositório.
3. Faça o commit na branch `main`.

A nova versão preserva:
- Logo textual `SOMOS TABS.`
- Fundo preto
- Verde-lima principal `#dfff38`
- Branco e cinzas da identidade existente
- Endpoint atual do formulário no Google Apps Script
- Rastreamento pelo parâmetro `?origem=`

Principais mudanças:
- Nova proposta de valor no hero
- Formulário de validação em 4 etapas
- Perguntas sobre momento de uso, solução atual, intenção e preço
- Jornada de desenvolvimento
- Diário do projeto
- Layout responsivo para celular
